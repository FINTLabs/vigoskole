Fake Vigo Skole

Demotjeneste for innsending, validering og inspeksjon av data om avgangselever fra ungdomsskoler til Vigo.

Tjenesten viser hvordan et API for Vigo Skole kan fungere, med Maskinporten-beskyttet innsending og en webapp for innsyn i opplastninger og valideringsresultater.

Hva systemet gjør

API-et tar imot JSON-LD for avgangselever, verifiserer avsender mot VIGO Kodeverk og godkjenner bare innsendinger som er uten feil.

Webappen lar fylkeskommune-brukere følge skoleår, fylker, ungdomsskoler og enkeltinnsendinger med tilhørende metadata og valideringsresultater.
